# LIFE QUEST｜人生技能树

把学习、运动、阅读和创造变成一场 RPG 冒险。完成任务获得经验值、金币和技能点，升级解锁四系技能树，点亮成就墙。

纯静态单页应用：**HTML5 + CSS3 + 原生 JavaScript**，无后端、无数据库、无账号系统、无第三方依赖，数据全部保存在浏览器 `localStorage`。

---

## 一、快速开始

### 方式 1：直接打开（最简单）

双击 `index.html`，用 Chrome 或 Edge 打开即可。已验证 `file://` 协议下功能完整。

### 方式 2：本地静态服务器（推荐）

```bash
# 在项目根目录执行任一种
python -m http.server 8787
# 或
npx serve -l 8787
# 或
npx http-server -p 8787
```

然后访问 <http://127.0.0.1:8787/>。

> 两种方式功能完全一致。使用静态服务器时 localStorage 绑定在 `http://127.0.0.1:8787` 上；直接打开时绑定在 `file://` 上。**两者存档互不相通**，切换方式请用「导出/导入存档」。

支持 Windows 11 上的 Chrome / Edge，也支持手机浏览器（已验证 390×844 视口）。

### 启动自检

`index.html` 内置了一段不依赖外部文件的启动自检脚本：

- 每个外链脚本都带 `onerror`，若某个文件 404 会被记录。
- 页面加载完成后若发现 `window.LQ` 未就绪或初始化异常，会在页面顶部弹出**红色提示框**，明确指出失败的文件、给出检查步骤，并提供「诊断资源加载状态」按钮（逐个文件检测 HTTP 状态码）与「重新加载页面」按钮。
- 正常情况下该提示不会出现，不影响界面。

## 三、玩法规则

### 角色与等级

| 项目 | 规则 |
| --- | --- |
| 初始等级 | LV 1，昵称「冒险者」（可修改，最多 12 字） |
| 升级需求 | `需求 XP = 100 + (当前等级 - 1) × 50`，即 1→2 需 100，2→3 需 150，3→4 需 200 … |
| 升级奖励 | 每升 1 级获得 **1 个技能点** |
| 经验溢出 | 一次获得大量经验可连续升级，多余经验保留 |
| 数值下限 | 经验、金币、技能点永不为负 |
| 等级称号 | LV1-2 初入冒险的旅人 / LV3-5 渐入佳境的探索者 / LV6-9 稳步前行的小达人 / LV10-15 自我管理的行者 / LV16-24 技能树的主人 / LV25+ 人生技能大师，另有青铜→传奇段位标识 |

### 每日任务

初始提供 4 个任务：

| 任务 | 属性 | 时长 | XP | 金币 |
| --- | --- | --- | --- | --- |
| 学习 30 分钟 | 学习 | 30 分钟 | 20 | 5 |
| 运动 20 分钟 | 健康 | 20 分钟 | 20 | 5 |
| 阅读 10 页 | 学习 | 10 页 | 15 | 4 |
| 完成一个创造性小任务 | 创造力 | 30 分钟 | 25 | 8 |

- **奖励范围**：经验 5 ~ 50 XP（默认 20），金币 1 ~ 20（默认 5），时长 1 ~ 480 分钟。超出范围自动收敛到边界值。
- **领取限制**：每个任务每天只能领取一次奖励。重复点击已领取的任务不会重复发放。
- **跨天重置**：日期变更后任务完成状态自动重置为新的一天，任务定义保留，历史记录不清空。
- **连续打卡**：当天完成至少 1 个任务即视为打卡；同一天完成多个任务连续天数只 +1；中断一天后重新从 1 开始。
- **任务上限**：最多 60 条；自定义任务可删除，内置任务删除后可用「恢复默认任务」找回。

### 属性分支

学习 📚 · 健康 💪 · 创造力 🎨 · 探索 🧭

### 技能树

四个分支，每支 4 个节点（根节点 → 左右两条路径 → 汇聚节点），共 **16 个节点**。

| 分支 | 节点链（消耗技能点） |
| --- | --- |
| 学习 | 专注力(1) → 知识积累(1) / 分析能力(2) → 融会贯通(3) |
| 健康 | 体能(1) → 规律作息(1) / 运动习惯(2) → 强健体魄(3) |
| 创造力 | 表达(1) → 设计(1) / 动手能力(2) → 创造之作(3) |
| 探索 | 尝试新事物(1) → 解决问题(1) / 探索精神(2) → 远行开拓(3) |

- 节点有三种状态：**未解锁**（灰暗）、**可解锁**（发光脉冲）、**已解锁**（实心高亮）。
- 汇聚节点需要**两个前置同时解锁**。
- 不满足条件时，详情面板会说明具体原因（缺前置技能 / 缺技能点，还差几点）。
- 已解锁节点不会重复扣除技能点。
- 全部解锁共需 28 个技能点（约 28 级）。
- 桌面端用 SVG 绘制带状态的连线（已解锁为实色实线、半通为虚线、未通为灰虚线）。

### 成就（9 个）

| 成就 | 条件 |
| --- | --- |
| 🌱 初次启程 | 完成第一个任务 |
| 🎯 小有成就 | 累计完成 10 个任务 |
| 📅 勤勉不辍 | 累计完成 30 个任务 |
| 🔥 坚持三日 | 连续 3 天完成至少一个任务 |
| 🗓️ 七日之约 | 连续 7 天完成至少一个任务 |
| ⭐ 等级提升 | 首次升到 2 级 |
| ✨ 技能解锁 | 解锁第一个技能节点 |
| 🧠 技能大师 | 解锁 8 个技能节点 |
| 🪙 财源滚滚 | 累计获得 200 金币 |

全部基于真实游戏数据自动判定，未达成的成就会显示实时进度（如 `进度 3 / 10`），不是固定装饰徽章。

### 数据管理

- **导出存档**：下载 `life-quest-save-YYYY-MM-DD.json`。
- **导入存档**：先校验数据结构，拒绝非法 JSON、缺少必要字段、版本高于当前程序的存档；确认后覆盖并在弹窗中先展示摘要，可一键先备份。
- **重置游戏**：需在弹窗中手动输入 `RESET` 才能执行，且提供「导出备份」按钮。
- **删除任务**：需要二次确认。

## 四、数据保存方式

- 全部数据存在浏览器 `localStorage`，键名 `lifequest.save`，格式为 JSON（`version: 1`）。
- 存档内容：角色信息、等级/经验/金币/技能点、每日任务、领取记录、技能树、成就、历史记录、设置。
- **存档损坏处理**：JSON 解析失败或结构异常时，会把原始内容备份到 `lifequest.save.corrupt`，然后创建新存档并提示，绝不静默丢数据。
- **字段修复**：加载时会校验并修复每个字段（非负数、奖励范围、非法属性、未知技能/成就 ID、非法日期），修复结果会提示用户。
- **版本升级**：存档带 `version` 字段，低版本自动升级，高版本给出提示并尽力读取。
- **防重复领取**：每次领取记录 `任务ID + 日期` 到 `claims`。即使把任务完成状态人为改回未完成，也无法重复领奖。
- **防日期回拨**：记录见过的最大日期（`maxSeenDate`）。若检测到系统日期被回拨，直接拒绝发放奖励，避免通过修改系统时间无限刷奖励。
- **存储不可用降级**：若浏览器禁用或不允许 localStorage（如某些隐私模式），自动降级为内存存储并在界面提示「刷新会丢失」。
- **容量限制**：历史记录保留最近 60 天，领取记录保留最近 400 条，超出自动裁剪。
- **网络**：页面**不发起任何网络请求**，数据不上传、不外发。

> ⚠️ 清除浏览器网站数据、使用无痕模式、更换设备或浏览器都会导致存档丢失，请定期「导出存档」备份。

## 五、免费部署指南（GitHub Pages）

> ❗ **必须上传完整的目录结构，不能只传 `index.html`。**
> 只上传 `index.html` + `style.css` 会出现「页面样式和中文正常，但所有按钮点了没反应」——
> 因为 JavaScript 所在目录缺失，脚本全部 404。现在遇到这种情况，页面会自己弹出红色提示框告诉你哪个文件没加载。

### 必须存在的文件（缺一不可）

```
index.html
style.css
.nojekyll
js/store.js
js/tasks.js
js/skills.js
js/achievements.js
js/ui.js
js/app.js
```

### 部署步骤

1. 在 GitHub 新建一个仓库，例如 `life-quest`（Public）。
2. 把项目文件上传到仓库根目录（`index.html` 必须在根目录）：
   ```bash
   cd 项目目录
   git init
   git add .
   git commit -m "feat: LIFE QUEST 人生技能树"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/life-quest.git
   git push -u origin main
   ```
   也可以在仓库页面点 `Add file → Upload files`，**把整个文件夹拖进去**（网页上传支持拖拽文件夹并保留目录结构，不要只拖单个文件）。
3. 仓库页面进入 `Settings → Pages`，`Source` 选择 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存。
4. 等待约 1 分钟，访问 `https://<你的用户名>.github.io/life-quest/`。

### 部署后自检（30 秒）

在浏览器地址栏依次打开下面三个地址，**都应该显示代码内容而不是 404**：

```
https://<你的用户名>.github.io/life-quest/
https://<你的用户名>.github.io/life-quest/js/app.js
https://<你的用户名>.github.io/life-quest/style.css
```

如果 `js/app.js` 是 404，就是文件没上传成功，重新上传 `js` 文件夹即可。

### 更新代码后没生效？

- 手机浏览器缓存很激进：在浏览器设置里清除该站点数据，或用无痕窗口打开。
- GitHub Pages 有约 1 分钟构建延迟，可在仓库 `Actions` 页面查看部署状态。

**其他免费选项**：Cloudflare Pages、Netlify（直接把文件夹拖到 netlify.com/drop）、Vercel、Gitee Pages。

> 部署后域名变了，localStorage 与原地址不互通，用「导出/导入存档」迁移数据。

## 六、交互兼容性说明

点击交互做了三层保障，鼠标与触屏都能用：

1. **主路径**：`document` 上的 `click` 事件委托（鼠标与触摸设备通用）。
2. **目标查找不依赖 `Element.closest`**：自己逐层向上遍历 `parentNode` 查找 `data-action`，避免老 WebView 缺少该方法时全部按钮失效。
3. **触摸兜底**：若某次触摸在 350ms 内没有产生 `click`（少数老旧 WebView 不会合成 click），由 `touchend` 直接执行该操作。两条路径互斥，不会重复执行，也不会吞掉用户的连续点击。

另外：`touch-action: manipulation` 消除移动端双击缩放带来的点击延迟；移动端按钮最小高度 40px，方便手指点击；任何初始化或运行时异常都会在页面上显示红色提示框，不会出现「点了没反应但毫无线索」的情况。
